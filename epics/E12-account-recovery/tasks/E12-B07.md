# E12-B07 · the "Continue without history" escape hatch is untested

## The defect

`design/screens/device-enrollment.md`'s most load-bearing requirement —
**"Continue without history" is reachable from the very first frame, never
gated behind the poll or the timeout** — is the user's only escape from a
waiting screen that (per `E12-B01`/`E12-B02`/`E12-B03`) they will currently
reach wrongly and can never leave by approval.

It is verified only by *reading* `device_enrollment_view.dart`. No
`testWidgets` renders the view, finds the button, and taps it.
`device_enrollment_controller_test.dart` tests the controller's
`continueWithoutHistory()` method directly, which cannot prove the button is
present, enabled, or unconditioned on `state.value`.

Two independent readers confirmed the source is correct. That is exactly the
evidence `skills/review` §2 rejects: *"a test that passes on broken code is
worse than no test"* — and here there is no test at all standing behind the
claim.

## Repro

`grep -rn "DeviceEnrollmentView" test/` → no `testWidgets` renders it.

## Expected

A rendering test asserting the button is present and tappable in the
`waiting` state **on the first frame** (before any poll completes) and in the
`denied` state, and that tapping it moves the controller to
`noRecoveryNotice`.

## Actual

Source-read verification only.

## Severity

**S4** — a coverage gap, not a user-visible defect: the implementation is
believed correct. Raised in importance by `E12-B01`/`B02`/`B03`, which make
this button the only working exit from the screen.

## Suggested shape

~20-30 lines added to the already-`files:`-listed
`device_enrollment_controller_test.dart` (or a sibling view test), using the
`GetMaterialApp` + `getPages` route-recording pattern that file already
establishes. Pump the view with `maxPolls` large enough that no timeout can
fire, assert the button before any `pump(pollInterval)`, then tap it.

## What this fix does NOT do

- Does **not** change `device_enrollment_view.dart` or the controller.
- Does **not** add or alter any design contract, or attempt to close
  `E12-B06`'s gating gap — a widget test is not a design gate.
- Does **not** address the `Code: [pairing code]` placeholder (deferred
  feature scope, tracked separately in the epic).
