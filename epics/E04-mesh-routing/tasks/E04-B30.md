# E04-B30 · Limit the bonded-cache refresh to devices that could run Nexora

## 1. Mechanism

`refreshNexoraCandidateUuidCaches` (E04-T07) now skips bonded devices whose Bluetooth major class is clearly not a Nexora host: audio/video, imaging (printers), wearables, peripherals, toys, health, networking. It still refreshes `PHONE`, `COMPUTER` (tablets), `UNCATEGORIZED` and devices with no class at all (review nit: a phone misreporting its class must not be left with a stale cache). The existing conditions are unchanged: SPP-capable, and not already advertising `NEXORA_DISCOVERY_UUID`.

Live check of the class filter against the real bonded set: Redmi 10 2022 reports class `5a020c` (major PHONE) and would still be refreshed. HOCO/soundcore/HAVIT (audio), MPT-II (imaging) and the Mi Band (wearable) would be skipped. ABGTL-DEV-00126 (`28010C`, major COMPUTER) would still be queried.

## What this task does NOT do

- Does not change `advertisesNexora`, the Discover filter, `unmaskIfNotBonded`, or which UUIDs are published.
- Does not remove the refresh. E04-T07 needs it so already-bonded peers learn the new record.
- Does not add a Kotlin test harness (none exists in this project).

## 2. Definition of Done

- [x] Refresh skips bonded devices whose major class is clearly not a Nexora host; PHONE, COMPUTER, UNCATEGORIZED and a missing class are still refreshed
- [x] `flutter build apk --debug` compiles clean (commit `b5a9e43`)
- [ ] Independent review (reviewed_by != executed_by)

## Open Questions

- OQ-E04-B30-1 (resolved in review round 1): the first version also skipped a missing or UNCATEGORIZED class. The reviewer showed why that matters: `unmaskIfNotBonded`'s raw bonded-set fallback applies only when NO bonded device already matches, so a skipped, misreporting Nexora phone could lose out to a different bonded device. Both are now refreshed. The remaining residual: a Nexora phone that reports a clearly non-host class (e.g. AUDIO_VIDEO) is not refreshed; that would require its OS to misreport its own Class of Device.
